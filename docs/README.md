# 📄 Документация по проекту "Геометрические фигуры"



## 1. Общее описание решения



Проект представляет собой набор модулей на языке Python для вычисления площадей и периметров основных геометрических фигур: круга, квадрата, прямоугольника и треугольника.



Каждый модуль (`circle.py`, `square.py`, `rectangle.py`, `triangle.py`) содержит две функции:


- `area()` — вычисление площади фигуры


- `perimeter()` — вычисление периметра фигуры


Модуль `test.py` содержит тесты для проверки корретности работы функций `area()` и `perimeter()` модулей `circle.py`, `square.py`, `rectangle.py`, `triangle.py`



## Математические формулы



### Площадь



- Circle: S = πR²

- Rectangle: S = ab

- Square: S = a²

- Triangle: S = ah



### Периметр



- Circle: P = 2πR

- Rectangle: P = 2a + 2b

- Square: P = 4a

- Triangle: P = a + b + c



## 2. Описание функций с примерами вызова



### Модуль `circle.py`



#### `area(r)`



Возвращает площадь круга с радиусом `r`.



**Параметры:**



&nbsp;	r (float) – радиус круга



**Возвращаемое значение:**



&nbsp;	S (float) – площадь круга



**Пример:**



```python

from circle import area

print(area(5)) # ~78.5398

```

#### `perimeter(r)`



Возвращает длину окружности по радиусу `r`.



**Параметры:**



&nbsp;	r (float) – радиус круга



**Возвращаемое значение:**



&nbsp;	S (float) – длина окружности радиуса r



**Пример:**



```python

from circle import perimeter

print(perimeter(5))  # 31.4159

```



### Модуль square.py

#### area(a)



Возвращает площадь квадрата со стороной a.



**Параметры:**



&nbsp;	a (float) – длина стороны квадрата



**Возвращаемое значение:**



&nbsp;	S (float) – площадь квадрата со стороной a



**Пример:**



```python

from square import area

print(area(4))  # 16

```



#### perimeter(a)



Возвращает периметр квадрата со стороной a.



**Параметры:**



&nbsp;   a (float) — длина стороны квадрата



**Возвращаемое значение:**



&nbsp;	S (float) – периметр квадрата по стороной a



**Пример:**



```python

from square import perimeter

print(perimeter(4))  # 16.0

```



### Модуль rectangle.py

#### area(a, b)



Возвращает площадь прямоугольника со смежными сторонами a и b (длина и ширина).



**Параметры:**



&nbsp;   a (float) – длина прямоугольника



&nbsp;   b (float) – вторая прямоугольника



**Возвращаемое значение:**



&nbsp;	S (float) – периметр прямоугольника с длиной a и шириной b



**Пример:**



```python

from rectangle import area

print(area(3, 7))  # 21.0

```



#### perimeter(a, b)



Возвращает периметр прямоугольника со смежными сторонами a и b.



**Параметры:**



&nbsp;   a (float) – длина прямоугольника



&nbsp;   b (float) – вторая прямоугольника



**Возвращаемое значение:**



&nbsp;	P (float) – периметр прямоугольника с длиной a и шириной b





**Пример:**

```python

from rectangle import perimeter

print(perimeter(3, 7))  # 20

```



### Модуль triangle.py

#### area(a, h)



Возвращает площадь треугольника с основанием a и длиной высоты h, опущенной на это основание.



**Параметры:**



&nbsp;   a (float) – основание



&nbsp;   h (float) – высота, проведённая к основанию



**Возвращаемое значение:**



&nbsp;	S (float) – площадь треугольника с основанием a и длиной высоты h, опущенной на это основание.



**Пример:**

```python

from triangle import area

print(area(10, 6))  # 30.0

```



#### perimeter(a, b, c)



Возвращает периметр треугольника по трём сторонам a, b, c.



**Параметры:**



&nbsp;   a, b, c (float) – стороны треугольника



**Возвращаемое значение:**



&nbsp;   P (float) – периметр треугольника со сторонами a, b, c



**Пример:**

```python

from triangle import perimeter

print(perimeter(3, 4, 5))  # 12.0

```

## 4. Тестирование

В проекте используется модуль unittest для проверки корректности функций вычисления площадей и периметров.

**Файл с тестами:** test.py

Запуск тестов:

```
python -m unittest test.py
```


**Тесты проверяют:**

- Корректность вычисления площади и периметра круга, квадрата, прямоугольника и треугольника

- Работу функций с нулевыми и дробными значениями

- Соответствие результатов математическим формулам
